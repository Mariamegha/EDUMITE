## 🧠 TECHNICAL ARCHITECTURE

### **File Tree**
```
src/
├── types/
│   └── navigation.ts         ← Types: ClusterType, NavigationItem, ClusterConfig
├── config/
│   └── navigationClusters.ts ← Cluster data: 5 clusters with items
├── store/
│   └── navigationStore.ts    ← Zustand: activeCluster, isInCluster
├── components/
│   ├── ClusterScreen.tsx     ← Cluster hub with card grid
│   └── DockNav.tsx           ← Smart bottom nav (morphs based on context)
└── App.tsx                   ← Routes: /cluster/:clusterId
```

### **Navigation Logic Flow**
```
1. User on Dashboard
   └→ DockNav shows: [ Dashboard, Learning, Sign, Visual, Support, OS, Settings ]

2. User clicks "Learning Tools"
   └→ Navigate to /cluster/learning-tools
      └→ ClusterRouteHandler extracts clusterId
         └→ Sets activeCluster in store
            └→ Renders ClusterScreen with cluster config
               └→ DockNav detects activeCluster
                  └→ Bottom nav shrinks to show cluster items

3. User clicks "AI Bot" card
   └→ Navigate to /ai-bot
      └→ DockNav detects /ai-bot belongs to Learning Tools cluster
         └→ Bottom nav shows cluster items (AI Bot, Roadmap, etc.)

4. User clicks "Back to Dashboard"
   └→ exitCluster() clears state
      └→ Navigate to /dashboard
         └→ Bottom nav expands to top-level
```
