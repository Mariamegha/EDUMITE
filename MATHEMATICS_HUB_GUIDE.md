# 🔢 Mathematics Hub - Virtual Reality Classroom

## Overview

The **Mathematics Hub** is a dedicated virtual reality classroom environment designed specifically for collaborative mathematics learning. Built on the FrameVR platform, it provides an immersive 3D space where students can visualize mathematical concepts, work together on problems, and access interactive learning tools.

---

## 🎯 Key Features

### 1. **Immersive VR Environment**
- Full 3D virtual classroom optimized for mathematics
- Navigate using WASD/arrow keys
- Spatial audio for natural conversations
- Real-time collaboration with students worldwide

### 2. **Interactive Mathematical Tools**
- **Virtual Whiteboards** - Draw equations, graphs, and diagrams
- **3D Graphing Calculators** - Visualize functions in three dimensions
- **Geometry Tools** - Interactive protractors, rulers, compasses
- **Equation Editors** - LaTeX-style mathematical notation support

### 3. **Topic-Specific Areas**
The classroom is divided into specialized zones:
- 📐 **Algebra Zone** - Linear equations, quadratics, polynomials
- ∫ **Calculus Corner** - Derivatives, integrals, limits
- 📊 **Geometry Space** - Shapes, theorems, proofs
- 📈 **Statistics Lab** - Data analysis, probability, distributions
- 📐 **Trigonometry Deck** - Angles, functions, identities
- 🔢 **Linear Algebra Hall** - Matrices, vectors, transformations

### 4. **AI Math Tutor Integration**
- Step-by-step problem explanations
- Real-time hints and guidance
- Personalized learning recommendations
- Instant feedback on solutions

### 5. **Collaborative Features**
- **Study Groups** - Form teams of 3-5 students
- **Problem-Solving Sessions** - Work together on challenging problems
- **Voice/Video Chat** - Natural communication
- **Screen Sharing** - Present solutions to the group
- **Shared Notebooks** - Save work to EDUMITE cloud

## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Edge recommended)
- Microphone and camera (optional but recommended)
- Stable internet connection (5+ Mbps recommended)

### First-Time Setup

1. **Navigate to Mathematics Hub**
   ```
   Menu → VR Study → Math VR Tab
   or visit: /study-vr and select "Math VR" tab
   ```

2. **Grant Permissions**
   - Allow microphone access for voice chat
   - Allow camera access for video (optional)
   - Allow XR spatial tracking for enhanced VR features

3. **Enter the Classroom**
   - Wait for the FrameVR environment to load (~3-5 seconds)
   - Your avatar will spawn at the entrance
   - Look around using mouse movement

4. **Basic Navigation**
   - **W/↑** - Move forward
   - **A/←** - Move left
   - **S/↓** - Move backward
   - **D/→** - Move right
   - **Space** - Jump
   - **Shift** - Run
   - **Mouse** - Look around

2. Navigate to your desired topic zone (Algebra, Calculus, etc.)
3. Click on whiteboards to start writing

1. Copy the invite link from the "Invite Study Partners" card
2. Share with your study group via chat/email
3. Wait for partners to join the VR room

6. Collaboratively solve problems

### Live Sessions
- Check the "LIVE" indicator in the header
- Join scheduled study sessions with peers and mentors
- Follow the session leader's guidance
- Participate in discussions and problem-solving

## 🔧 Troubleshooting

### Common Issues

#### VR Room Not Loading
**Problem**: Black screen or infinite loading
**Solutions**:
- Refresh the page (F5)
- Clear browser cache
- Check internet connection
- Try a different browser
- Disable browser extensions

#### No Audio/Video
**Problem**: Can't hear others or camera not working
**Solutions**:
- Check browser permissions (click padlock icon)
- Test microphone/camera in device settings
- Restart browser
- Try different audio input device
- Check FrameVR audio settings in-room

#### Lag/Stuttering
**Problem**: Choppy movement or freezing
**Solutions**:
- Close other browser tabs
- Reduce video quality in settings
- Move closer to WiFi router
- Use wired ethernet connection
- Restart computer

#### Avatar Not Moving
**Problem**: Can't navigate with WASD
**Solutions**:
- Click inside the VR iframe
- Check keyboard is working (test in another app)
- Reload the page
- Try arrow keys instead of WASD
